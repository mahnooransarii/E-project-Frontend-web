# 🎨 Galleria Art Collection - Premium E-Project Portal

Welcome to **Galleria Art Collection**, an interactive, responsive, and feature-rich online Fine Art Gallery designed for art enthusiasts, interior designers, and collectors. This portal showcases various artistic mediums including Abstract Art, Landscape Paintings, Acrylic, Canvas work, OHP Sheets, and Fabric Art with a seamless user experience.

---

## 🚀 Key Features

- **Dynamic Art Catalog:** Built with a fully dynamic Javascript dataset that renders high-quality paintings seamlessly.
- **Categorized Galleries:** Separate dedicated modules for Abstract Expressionism, Landscape Realism, OHP Sheets, and more.
- **Smart View Details Toggling:** Zero-flicker single-page application (SPA) style routing to view painting insights without reloading the webpage.
- **Automated Word Document Exporter:** Users can download an instantly structured `.doc` catalog sheet containing specifications, dimensions, artist quotes, and descriptions with one click.
- **Clean UI & Responsive Grid:** Powerfully styled using Bootstrap 5 utility classes with pixel-perfect `text-center` alignment and smooth hover behaviors.

---

## 🛠️ Tech Stack Used

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Framework:** Bootstrap 5 (Fully Responsive)
- **Icons:** Bootstrap Icons
- **Storage:** LocalStorage (State management for item detail tracking)
